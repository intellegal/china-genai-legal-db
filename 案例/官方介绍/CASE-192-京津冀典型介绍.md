# 京津冀数字版权典型介绍

从法律数据库读取的法院发布案例介绍，非原判；全文已读。

【基本信息】
  一审案号：（2024）津0101民初330号
  二审案号：（2024）津01民终9425号
  原告：宋某
  被告：某网络公司
  【
案情】
  宋某为摄影师，曾为某博主拍摄了两段古风妆造视频，该视频发布在某网络平台。某网络公司系某小程序的运营者，其未经授权擅自将上述视频作为素材，上传至该小程序，该小程序的用户只需上传面部照片，即能以该视频为素材模板制作换脸视频。该视频除模特脸部特征不一致之外，其余内容与原始视频均一致。宋某主张某网络公司的上述行为侵害其对涉案作品享有的著作权，故向法院提起诉讼。一审法院判决某网络公司赔偿宋某相应经济损失及维权合理开支。一审法院判决后，某网络公司提起上诉，二审法院判决驳回上诉，维持原判。
  法院生效判决认为，涉案原始视频虽时长较短，但体现了作者的个性化编排和对场景的选择，具有一定独创性，构成视听作品，宋某作为原始视频的著作权人，依法对该视频享有著作权。某网络公司未经宋某许可在其运营的小程序中使用宋某创作的视频，作为“AI换脸”的素材模板展示，并提供给用户制作“换脸”视频使用，换脸后的视频通过AI算法将原始视频进行局部替换合成，二者构成实质性相似，侵犯了宋某对涉案作品享有的著作权，依法应承担相应的民事责任。
  【
典型意义】
  本案系生成合成类算法应用场景下的典型案例。本案裁判有效规制了利用AI换脸技术对他人作品进行局部合成，侵害原创短视频作品著作权的行为，依法保障了著作权人的合法权利，为AI换脸程序的运营主体提供了明确的司法裁判指引。本案对规范短视频领域的版权秩序，促进新技术、新业态的健康发展具有积极作用。
