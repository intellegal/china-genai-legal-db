# （2024）渝0113民初1435号 民事判决书

赵某某与某某公司,黄某某肖像权纠纷一审民事判决书



重庆市巴南区人民法院
民事判决书

(2024)渝0113民初1435号


　　原告：赵某某。
　　委托诉讼代理人：张某某，重庆渲滈言律师事务律师。
　　被告：某某公司，住所地重庆市巴南区鱼洞街道智云大道1580号4幢1单元1-1-自编号xxx统一社会信用代码91500113MACH1WWD7J。
　　法定代表人：黄某某。

　　原告赵某某与被告某某公司(以下简称壹思唯行公司)肖像权纠纷一案，本院于2024年1月11日立案后，依法适用简易程序(小额诉讼)，由审判员郭静独任审判，于2024年2月19日公开开庭进行了审理。原告赵某某的委托诉讼代理人张贵琼到庭参加诉讼，被告壹思唯行公司经本院依法传唤，无正当理由未到庭参加诉讼。本案现已审理终结。

　　原告赵某某向本院提出诉讼请求：1.依法判令被告向原告赔礼道歉，并在被告运营的“秀拍换脸秀”手机抖音小程序的首页显著位置连续30天刊登对原告的致歉声明，内容需经法院同意；2.判令被告赔偿原告经济损失及合理维权费用合计10000(经济损失6000元、合理维权费用即律师费2000元、精神抚慰金2000元)；3.依法判令由被告承担本案的诉讼费用。事实与理由：被告运营一款名为“秀拍换脸秀”的手机抖音小程序，在该软件中，被告将包含原告肖像在内的古风视频上传为模板提供用户换脸使用并牟利。用户在上传照片后，需要强制观看25秒的商业广告，便能够自行创设换脸视频，形成除脸部特征不同之外其他内容仍为网红或明星的肖像视频。本案原告赵某某是网络红人、汉服模特，系著名化妆造型艺术家杨树云老师的亲传弟子。因长相清丽，古装扮相异域风、可人风均游刃有余，故经常受摄影师邀约或自拍国风造型短视频，在抖音平台上进行发表，备受粉丝喜爱。其抖音号为“BIMOMO816”、昵称“笔墨伺候”，粉丝人数在22.1万人，作品总点赞量271.1万人次，原告于圈内圈外均有较高的知名度和人气度，参加商演、商拍活动、带货推广，其本人及作品具有巨大的商业价值。被告在原告未授权同意的情况下，在其运营的“秀拍换脸秀”手机抖音小程序，上传以原告肖像为原内容的视频提供给用户换脸使用而非法牟利，损害了原告的合法权利。原告为维护其合法权益，故向法院提起诉讼。

　　被告壹思唯行公司未到庭亦未提交书面答辩意见。

　　本院认为，任何组织或者个人不得以丑化、污损，或者利用信息技术手段伪造等方式侵害他人的肖像权。未经肖像权人同意，不得制作、使用、公开肖像权人的肖像。原告具有一定网络热度，抖音“BIMOMO816”账号经原告本人实名身份认证，其在抖音账号中发布的视频资料中的肖像权应受到法律保护。“秀拍换脸秀”手机抖音小程序由被告开发运营，被告在该软件中上架使用了原告在“BIMOMO816”抖音号中发布的个人肖像视频，供用户观看商业广告后使用原告的照片进行面部替换。被告未经原告授权同意，以营利为目的使用含有原告肖像的视频，已经侵害了原告的肖像权。
　　关于原告提出的要求被告赔礼道歉、刊登致歉声明的诉讼请求，本院认为赔礼道歉的范围一般应与侵权所造成不良影响的范围相当，故被告应在“秀拍换脸秀”手机抖音小程序首页显著位置刊载致歉声明，持续时间不少于七日，内容须经本院审核同意。关于原告提出的要求被告赔偿经济损失、维权支出以及精神损害抚慰金的诉讼请求，本院结合原告的知名度、侵权行为的具体情节、对原告造成的影响、当前的市场因素及原告实际支出等因素，酌情确定被告赔偿原告全部损失合计3500元。
　　据此，依据
《中华人民共和国民法典》第一千零一十八条、第一千零一十九条、第一千一百六十五条，《中华人民共和国民事诉讼法》第一百四十五条、第一百四十七条之规定，判决如下：

　　一、被告某某公司应于本判决生效之日起十日内在“秀拍换脸秀”手机抖音小程序首页显著位置刊载致歉声明对使用原告赵某某肖像一事赔礼道歉，连续保留七日，内容须经本院审核；
　　二、被告某某公司应于本判决生效之日起十日内赔偿原告赵某某3500元；
　　三、驳回原告赵某某其余诉讼请求。
　　如果未按本判决指定的期间履行给付金钱义务，应当依照《中华人民共和国民事诉讼法》第二百六十四条规定，加倍支付迟延履行期间的债务利息。
　　案件受理费40元，减半收取20元，被告某某公司负担。
　　本判决为终审判决。
　　本判决发生法律效力后，当事人应自觉履行判决的全部义务。一方不履行的，权利人可以向本院申请强制执行，申请执行的期间为二年，该期间从法律文书规定履行期间的最后一日起计算。
