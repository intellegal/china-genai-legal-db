# 孔某模型训练著作权纠纷管辖裁定

从法律数据库可见法院文书全文读取并保存。公开案号：（2024）京73民辖终6号；2024-02-01。保留原文匿名。

北京知识产权法院
民事裁定书

(2024)京73民辖终6号

当事人
　　上诉人(原审被告)：某1公司。
　　被上诉人(原审原告)：孔某。
　　原审被告：某2公司。
　　原审被告：某3公司。

审理经过
　　上诉人某1公司(以下简称某1公司)与被上诉人孔某、原审被告某2公司(以下简称某2公司)、原审被告某3公司(以下简称某3公司)著作权权属、侵权纠纷一案，不服北京互联网法院(以下简称一审法院)作出的(2023)京0491民初19965号民事裁定(以下简称一审裁定)，向本院提出上诉。

二审上诉人诉称
　　某1公司上诉称：一、诉请是确定管辖的要素，本案诉争行为“人工智能模型的训练行为”通常不在互联网上发生。二、一审法院超出孔某诉请范围径直认定管辖，一审法院就本案无管辖权。三、一审法院未经审理即在管辖权异议阶段作出实体认定，并根据其实体认定结论倒推维持管辖应予纠正。四、“与互联网有关的行为”与“在互联网上发生的侵权”不同，本案侵权与否的判断节点是通常在本地进行的人工智能模型训练行为，依法不属于一审法院管辖范围。五、本案涉及虚列被告制造管辖点。六、一审法院即便继续审理本案，其管辖范围亦不包括非互联网上的“人工智能模型训练行为”。七、上海市黄浦区人民法院具有稳定全面的管辖权。综上所述，请求撤销一审裁定，将本案移送至上海市黄浦区人民法院审理。

二审被上诉人辩称
　　孔某答辩称，某1公司系涉案软件的开发者和运营者，为本案适格被告。同时，本案属于“在互联网上侵害在线发表或传播作品的著作权或者邻接权而产生的纠纷”，应当由互联网法院管辖。被控侵权行为包括在互联网中抓取孔某作品的行为、在互联网上向公众提供AI模型的行为以及将抓取的作品作为训练物料输入模型进行分析处理的行为，且无证据证明该训练行为单独发生于线下，而上述行为密不可分，应视为一个整体。一审法院对本案具有管辖权。

本院认为
　　本院经审查认为：
　　本案系著作权权属及侵权纠纷，属于知识产权侵权之诉。
《中华人民共和国民事诉讼法》第二十九条规定：“因侵权行为提起的诉讼，由侵权行为地或者被告住所地人民法院管辖。”《最高人民法院关于审理著作权民事纠纷案件适用法律若干问题的解释》第四条“因侵害著作权行为提起的民事诉讼，由著作权法第四十七条、第四十八条所规定的侵权行为的实施地、侵权复制品储藏地或者查封扣押地、被告住所地人民法院管辖。”《最高人民法院关于互联网法院审理案件若干问题的规定》第二条“北京、广州、杭州互联网法院集中审理所在市的辖区内应当由基层人民法院受理的下列第一审法院......(五)在互联网上侵害在线发表或者传播作品的著作权或者邻接权而产生的纠纷。”《中华人民共和国民事诉讼法》第三十六条规定：“两个以上人民法院都有管辖权的诉讼，原告可以向其中一个人民法院起诉；原告向两个以上有管辖权的人民法院起诉的，由最先立案的人民法院管辖。”
　　本案中，孔某主张的被诉侵权行为包括在互联网中获取并使用其作品进行模型训练以及向网络用户提供前述模型的行为，上述抓取作品和提供被控侵权作品的行为均发生在互联网上，属于《最高人民法院关于互联网法院审理案件若干问题的规定》第二条规定的互联网法院可以管辖案件的范围，而中间的训练行为与前述行为密切相关，不宜单独分割处理，故互联网法院对本案整体具有管辖权。关于某1公司是否为适格被告的问题，本院认为，管辖阶段虽应对作为管辖连接点的主体是否适格进行审查，但应以初步证据是否能指向该主体为限。孔某主张被诉侵权行为主体包括涉案软件某AI的开发和运营者。本案中，孔某提交的初步证据显示，某1公司是某微信公众号运营主体，其官网提供了涉案软件的下载二维码。同时，某1公司亦为某系列文字、图形商标的持有人，商标标志与涉案软件小某书平台官方主页头像一致等。上述证据已初步指向某1公司为涉案软件的运营主体之一，故其被告主体适格。至于某1公司是否实际运营了涉案软件以及是否应当承担侵权责任则有待于本案实体审理阶段进行判断。因此，根据前述法律规定，在某1公司住所地位于北京市的情况下，一审法院对本案有管辖权。
