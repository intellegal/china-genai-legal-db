# （2024）浙01民特572号 民事裁定书

A公司;钟xx申请撤销仲裁裁决特殊程序：申请撤销仲裁裁决民事裁定书



浙江省杭州市中级人民法院
民事裁定书

(2024)浙01民特572号


当事人
　　申请人：A公司，住所地浙江省杭州。
　　被申请人：钟xx。

审理经过
　　申请人A公司申请撤销仲裁裁决一案，本院于2024年12月6日受理后，依法组成合议庭进行了审理。本案现已审理终结。杭州市XX区劳动人事争议仲裁委员会作出的浙杭XX劳人仲案(2024)XXXX号仲裁裁决，申请人向本院申请撤销该裁决：仲裁裁决认定事实及适用法律确有错误，依法应予撤销。一、申请人与被申请人就变更劳动合同中的岗位及薪资事项均已达成一致。首先，申请人于仲裁期间提交的证据3聊天记录中已经明确显示，被申请人于2024年3月5日主动向公司申请转岗，并于2024年3月8日与申请人就工资数额、结构及双休待遇部分达成一致；而证据5也显示，被申请人自行草拟了调岗后的电商运营计划，并实际已在3月后开始进行电商运营的工作并一直持续到本案起诉。此外，被申请人向仲裁委提交的仲裁申请本身也承认了调岗及双休的事实(仲裁裁决P1末尾、P2开头)，因此被申请人的调岗及工作时间变更等事实均是由双方认可并达成一致的。基于以上事实，按照仲裁裁决的逻辑，在申请人、被申请人明确就调岗及双休待遇达成一致的情况下，双方却唯独“遗漏”了最基本也是最关键的调岗后薪资待遇部分未商议一致，且被申请人在未与申请人就薪资达成一致的情况下依旧自行制定运营计划并持续从事电商运营工作数月，显然与常理及本案事实相悖。因在面试过程中未发现能够熟练使用AI工具生成图像的应聘者，申请人招聘被申请人并由公司创始人亲自培训其掌握相关技能，并作为核心员工推进AIGC应用项目，且整个AI项目部是受到投资人资金支持的；而被申请人向公司申请转岗的电商部门，仅为测试应用成果的辅助团队，自负盈亏且收入主要依赖销售提成。因此，在项目资金支持度、工作难度及可替代性均完全不同的岗位下，被申请人的转岗后的薪资有所降低，完全合情合理，其转岗行为甚至也是公司本着照顾怀孕员工身心健康的人道主义而勉强同意的。其次，虽然仲裁裁决未明确说明，但从“工资差额”的天数计算可以发现，仲裁庭实际已认定双方就双休达成一致，却对于工资的变更不予认定；且同样在双方未签订书面的变更劳动合同文书的情况下，仲裁庭能够根据银行流水等事实认定调岗前《劳动合同》的薪资标准由双方约定的3957元+绩效变更为8000元，却在被申请人主动申请转岗，自行承认“工资降一半”，且已实际到岗数月、工作期间从未对工资数额提出异议的情况下，认定申请人变更劳动合同达成一致的主张于法无据，实在有失公平。仲裁裁决枉顾上述诸多事实，无视AI美工岗位与普通电商运营岗位之间的巨大差异，在双方已就调岗调薪达成一致的情况下，仅根据“银行流水及庭审陈述”确定一个与双方《劳动合同》以及运营岗薪资均不一致的工资标准8000元，属于事实认定的重大错误，其适用《劳动法》第50条等要求申请人支付额外的工资，亦属于明显适用法律错误，应当依法予以撤销。二、申请人辞退被申请人是基于事实和法律规定的合法合理行为，不存在违法解除劳动合同的情形。首先，被申请人提交的《公司停业通知书》，其产生的原因正是被申请人作为AI美工应聘后，无法胜任工作并要求转岗，导致公司的核心项目，即对于AIGC的应用计划完全搁置，且申请人短时间内难以再招聘一位能够掌握主流AIGC软件的成员。随着项目申报时间临近，公司创始人讨论后，决定在4月底公示，并于6月正式解散申请人公司，相关公告在当时已张贴于办公室大门且《公司停业通知书》已由员工签收；至于被申请人向仲裁庭提交的与未收到停业消息员工的聊天记录，其聊天对象在通知发送前即已从公司离职，且所有通知均为线下拿取签收，自然并未收到通知。通知发送后，公司核心员工苏XX、姚XX、陈XX表示愿意学习并推进项目，因此申请人在20天内对上述员工进行培训，并由三人分别掌握部分原先培训被申请人的AIGC软件(具体见证据10)。培训取得显著成效，并被收录进AIGC解决方案供应商名录后，申请人于2024年5月31日召开员工会议，决定放弃解散公司，继续运营项目；该会议申请人于2024年5月22日提前通知被申请人参会，并当面要求被申请人继续履行劳动合同。另外，被申请人在仲裁申请中已自行承认其于2024年6月6日前往申请人办公地，并“发现被申请人依旧有人员办公”(见仲裁裁决P3第3行)，可见被申请人对申请人撤销停业、继续运营的状况是明确知晓的，但被申请人最终既未出席会议，也未按时到岗。因此《公司停业通知书》的产生，从始至终仅是公司运营过程中的插曲，申请人确曾有停业的想法，但也确经员工努力挺过难关，从而能够继续运营；且申请人在决定继续运营后也及时通知被申请人继续履行劳动合同，而被申请人是在明确知晓申请人仍在运营的情况下自行拒绝到岗并无故旷工。申请人甚至在被申请人全程旷工的6月依旧按约发放工资并为其缴纳社保，切实履行《劳动合同》约定的自身义务，以实际行动表示继续履行劳动合同并要求被申请人一并履行，仲裁裁决中“未能提供充分有效证据证明被申请人(公司)之后要求申请人(钟xx)继续履行劳动合同”的说法与事实完全相悖，属于明显的错误认定。鉴于以上情况，申请人与被申请人之间劳动关系的结束，应当以申请人向被申请人发送的正式《开除通知书》为准，而非《公司停业通知书》。自案涉《劳动合同》签订开始至《开除通知书》发送为止，申请人从未向被申请人正式表示解除劳动合同的意愿；此外，申请人也在与劳动监察部门沟通的过程中向其明确表示不解除劳动关系。最终鉴于被申请人存在简历造假，欺诈申请人签订劳动合同的情形，且经申请人表示要求其到岗后仍旧连续旷工，申请人迫于无奈，基于《劳动合同法》39条第2款、第5款的规定，与被申请人解除劳动合同，是完全合法合规的，不存在违法解除的情况。因此，仲裁裁决基于《公司停业通知书》认定申请人违法解除劳动合同，其认定基础错误，认定的结果亦不符合本案事实；且仲裁庭核算的被申请人月均工资，基于上述第一点的阐述，亦不符合被申请人的真实薪资情况。仲裁裁决基于错误的事实认定，适用《劳动合同法》第87条要求申请人支付违法解除劳动合同赔偿金，属于明显的认定事实和适用法律错误，应当依法予以撤销。
　　被申请人钟xx答辩：一、本案仲裁裁决书所适用的法律正确。被申请人钟xx与申请人A公司之间存在劳动关系，因申请人拖欠工资等事由申请仲裁，故适用劳动法和劳动合同法的规定审理并不存在错误适用的情况，适用法条也是正确的。二、被申请人提交的证据并不存在伪造的情况。被申请人提交的证据材料在仲裁阶段已经提交仲裁委核实，且仲裁委也将证据送达申请人A公司。在仲裁阶段对方未提出异议，也未提交证据证明被申请人提交的证据材料有篡改和拼接情况。仲裁期间与被申请人仅就证明对象上存在差异。可见，其对证据的真实性是认可的，不存在其申请书所称的伪造的情况。三、XX劳动人事争议仲裁委员有管辖权，且审理过程中不存在违反程序的情况。在仲裁过程中，申请人经合法传唤后在开庭时出席，也就被申请人的仲裁请求和证据材料发表充分的意见，也提供与案件事实相关的证据材料，仲裁阶段审理并不违反法定程序。四、申请人在本次撤销诉讼中并未举证证明被申请人有隐瞒证据之情形，申请人在本次申请书中只是对事实有争议，但并未提供充足的证据证实被申请人有隐瞒证据的情况。五、申请人并无事实依据认定仲裁员在仲裁该案时有索贿受贿、徇私舞弊、枉法裁决的行为。综上，根据劳动争议仲裁法49条的规定，用人单位撤销的情形有六种，只有符合这六种情形之一才可以申请撤销，但申请人的申请理由没有证据予以证明，均不符合撤销的情形。对于钟xx来说，依法拿到工资维护其合法权益是劳动者的一项最基本权利。故恳请驳回申请人的请求，维护被申请人的合法权益。
　　本案审理期间，申请人A公司向本院提交证据：微信聊天记录、运营计划及上架记录、照片、签收单、录音资料、会议记录、工资条及停保记录、简历、参保证明、毕业证书、开除通知书。
　　本案审理期间，被申请人钟xx向本院提交证据：微信聊天记录、手机截图。

本院认为
　　本院认为：
《中华人民共和国劳动争议调解仲裁法》第四十九条第一款规定：“用人单位有证据证明本法第四十七条规定的仲裁裁决有下列情形之一，可以自收到仲裁裁决书之日起三十日内向劳动争议仲裁委员会所在地的中级人民法院申请撤销裁决：(一)适用法律、法规确有错误的；(二)劳动争议仲裁委员会无管辖权的；(三)违反法定程序的；(四)裁决所根据的证据是伪造的；(五)对方当事人隐瞒了足以影响公正裁决的证据的；(六)仲裁员在仲裁该案时有索贿受贿、徇私舞弊、枉法裁决行为的”。本案中，关于申请人A公司提出的岗位及薪资变更是否达成一致的认定属于事实认定的范畴，而不属于前述法定的可申请法院撤销仲裁裁决的审查事由。同时，仲裁裁决依据其认定的事实裁定申请人构成违法解除，适用法律亦正确。因此，申请人在本案中提出的撤销理由均不能成立，无法予以采信。综上，本院对申请人A公司撤销仲裁裁决的申请依法予以驳回。依照《中华人民共和国劳动争议调解仲裁法》第四十九条、《中华人民共和国民事诉讼法》第一百五十七条第一款第(九)项之规定，裁定如下：

裁判结果
　　驳回申请人A公司要求撤销杭州市XX区劳动人事争议仲裁委员会作出的浙杭XX劳人仲案(2024)XXXX号仲裁裁决的申请。
　　本案案件受理费400元，由A公司负担。
　　本裁定为终审裁定。
