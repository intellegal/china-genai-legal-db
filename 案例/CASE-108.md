# 作品抓取与模型训练一体审理：互联网法院管辖

- 首版收录依据：已取得裁判文书正文；具体审级、文书类型及核验限制见本条和正文。

- 法院：北京知识产权法院；公开案号：（2024）京73民辖终1号。
- 原告：薛某某；被告为三家公司，原文匿名。
- 程序：管辖异议上诉，终审裁定；实体判决及后续程序待核。
- 原审：北京互联网法院（2023）京0491民初19962号民事裁定，未取得独立原审文本。
- 来源：法律数据库、互联网公开渠道。

## 争点

原告主张软件开发、运营者从互联网抓取其作品用于模型训练并向网络用户提供模型。上诉公司称训练通常在线下完成，不属互联网法院管辖；并指控原告虚列北京公司制造管辖连接点，要求移送上海黄浦法院。

## 法院认定与结果

法院认为，抓取作品、向网络用户提供被控侵权作品的行为发生在互联网上，中间的训练行为与前述行为密切相关，不宜分割，互联网法院对本案整体具有管辖权。

适格被告在管辖阶段仍需审查，但以初步证据是否指向该主体为限。北京公司系相关公众号运营者，官网提供软件下载二维码，并持有相关系列商标，与官方主页头像相符，已初步指向其为运营主体之一。其住所地在北京，原审法院有管辖权。

裁定驳回上诉、维持原裁定，为终审裁定。没有实体损害赔偿判项。

## 边界

是否实际运营、是否承担侵权责任，法院明确留待实体审理。裁定没有判定模型训练侵权、合理使用成立与否，也没有确认训练必然在线上完成。整体管辖结论建立在本案网络抓取、训练及向用户提供模型的行为联系上，不能推导所有离线模型训练案件均由互联网法院管辖。
