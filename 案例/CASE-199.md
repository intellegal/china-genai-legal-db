# 付费换脸模板使用2435次：南京鼓楼法院酌定经济损失1万元

- 首版收录依据：已取得裁判文书正文；具体审级、文书类型及核验限制见本条和正文。

法院：江苏省南京市鼓楼区人民法院。刘某1诉深圳市某甲公司一般人格权纠纷。

本件作为明确涉及换脸服务的历史案件定向补采，不据此扩大到全部2023年前案件。

法院查明，被告员工将原告汉服视频上传至其运营软件，供付费用户使用；后台显示使用2435次，2021年12月14日上架、12月31日下架。原告在抖音、微博分别约有18.9万、19.4万粉丝。证据包括AI换脸秀视频及截图。

法院认定未经许可营利性使用构成肖像权侵权，结合肖像商业价值、使用次数、用途、时间，酌定经济损失1万元。2435次是本案损害酌定因素，不能折算为普遍适用的每次使用赔偿单价；判决亦未展开模型或换脸技术鉴定。

主文要求生效后十日内书面赔礼道歉及赔偿1万元。未支持原告要求的官网及APP显著位置连续30日公开道歉；逾期不道歉时，由法院在全国发行报刊公开判决相关内容、费用由被告负担。该替代执行安排不能记为直接判令登报道歉。

原文主文“赔偿原告刘某11万元”系匿名姓名“刘某1”与“1万元”连写；结合理由明确酌定1万元，不能误录为11万元。原文保留。是否上诉及生效情况尚未核实。
