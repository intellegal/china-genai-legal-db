# 配音员诉声入人心：声音相似与身份可识别性

- 首版收录依据：已取得裁判文书正文；具体审级、文书类型及核验限制见本条和正文。

- 法院：成都铁路运输第一法院；公开案号：(2024)川7101民初8969号，判决图片第1页已核。
- 被告：成都声入人心网络科技有限公司；原告姓名在公开图片遮盖，不推断。
- [判决正文](裁判文书/CASE-228.md)：互联网公开渠道取得的10页判决图片，经逐页识别、校稿。

## 已核裁判理由与结果

第8—9页针对“超级配音”软件“孟帅”声音，法院认为不附原告肖像时，公众聆听不能将该声音联系至原告，也未达识别声音主体程度。原告提出云知声AI开放平台声纹比对，被告比对结果与其不一致，且出现男女声音相似度超过60%的情况，法院认为该软件比对结果不能作为认定本案侵权事实的依据。不能将60%作为普遍司法阈值。

法院回应原告提交的北京互联网法院先行案例，指出其具有参考性，但该案证据能够证明主体关联及利用AI侵害声音权益，与本案事实不同。本案不仅涉及身份可识别性，还涉及基础侵权证据不足，不能只归纳为配音员不知名所以败诉。

第9页主文：驳回原告全部诉讼请求，案件受理费795元由原告负担。关于合理范围内相似声音的容忍，说理以缺乏侵权证据为条件，不是概括允许克隆任何人的声音。

## 程序及缺口

第1页显示2024-06-14立案，2024-07-22转普通程序独任审理，2024-07-25开庭。第10页列向成都铁路运输中级法院上诉的途径，不能据此推断已经上诉。落款日期受印章、水印遮挡，尚不填写具体日期。转载说明称近日生效，该状态尚未通过法院材料独立核验。

第2—7页已核：原告诉请经济损失70000元、精神损害5000元、律师费4500元及停止删除、置顶道歉30天等，均为请求，未获支持。第5页显示原告购买音包后进行了降调处理，再比对声音；其提交的四项比对数值为88.32%、90.66%、90.93%、95.35%，是提交证据的显示值，非法院认可的身份识别概率。

被告提交多份委托协议及声音授权书、技术说明和文献，主张采用开源或授权声音多维合成。判决记载这些证据及其证明目的，不能据此概括法院已经全面审计并认可训练集合法性。法院承认原告声音有商业价值和原告有权起诉；最终系实体驳回诉请，不是采纳被告无利害关系抗辩而驳回起诉。
