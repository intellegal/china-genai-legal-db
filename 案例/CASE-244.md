# AI伴聊智能体自动化操作：行为保全与平台权限

- 材料类型：官方行为保全介绍；未取得裁判全文。
- 官方发布机关／供稿单位：广州互联网法院。
- 官方材料名称：《“智能体”越界操作？广互公开开庭审理涉AI对话软件网络不正当竞争纠纷案》。
- 引用边界：仅据官方报道介绍具体行为保全措施；实体责任尚未据此确定，不得表述为实体胜诉或裁定原文。

- 广州互联网法院；案号未披露。两原告为某科技公司、某系统有限公司，被告某科技有限公司。
报道时实体案择期宣判，行为保全已裁定并履行。

## 当事人争议

原告指控被告开源运营的AI伴聊软件调用系统无障碍权限，代替用户操作其对话平台、规避技术管理措施，要求停止开发分发宣传及赔偿10万元。被告主张免费开源、非营利，读取和操作由第三方组件完成，用户上传脚本已接入内容审核。这些是双方陈述，不能写成法院最终事实认定。

法院组织质证账号接管、底层权限读取、角色脚本输出、版本伪装和申诉指引等，并将是否规避技术措施、双重授权及商业道德等列入辩论。尚未形成可据报道确认的实体责任结论。

## 已确认的保全措施

报道明确裁定立即停止以下行为：

1. 提供涉案智能体软件下载安装，及调用底层权限避开涉案平台技术管理措施。
2. 传播规避该平台风控的教程及相关内容，并删除已有内容。
3. 后续处理已获取的平台用户数据，并删除数据。
4. 连接角色库中破坏大模型安全风控、诱导不良信息的脚本，须断开相应链接。

原告确认被告已履行全部裁定内容。不得将“停止开发”的诉请扩大为已确认的保全主文，也不概括为封禁所有开源智能体或所有角色脚本。10万元仅为索赔，不是判赔。

## 核验边界

保全不等于实体终局认定；本案未证明法院已确立普遍的双重授权规则。具体裁定日、案号、担保、期限、复议及实体判决未披露。

法律数据库全文“角色脚本*智能体”被拆词成36条噪音，停止逐篇读取；改为“无障碍*伴聊”，司法案例无结果。已取得官方庭审和保全信息，未取得裁定原文。不得因没有判决而虚填裁判尺度。
