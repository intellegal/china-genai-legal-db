# 中国生成式AI法律数据库

全量采集现行法律规定以及公开案例。

| 内容 | 数量 |
|---|---:|
| 案例记录 | 230 条 |
| 裁判文书正文 | 164 份 |
| 无裁判文书正文的案例 | 66 条 |

| 直接管理参考规范 | 6 项 |

案例记录由164条有正文案例和66条无全文案例组成；规则及参考资料共46项。CASE-259保留法院典型介绍与《法人》记者采访两个版本，企业说明、律师点评与法院介绍分开，原判等缺口仍在。CASE-277保存二审公开HTML转载文字，法院原站、导入链、影印件、独立一审及证据附件等仍待核/补。CASE-276依据山东高法官方介绍整理，本案完整分栏文字已保存，原判、案号、审级、裁判日期及生效情况仍待补；下游张店单篇显示作者删除，未恢复其原文。CASE-275依据央视新闻及具名法官受访报道整理，报道全文已保存，仍非裁判文书或法院独立发布。正文取得含已注明遮盖、省略及转载底本限制的公开脱敏版本，不等于全部取得法院签章原件或无删节文书。
